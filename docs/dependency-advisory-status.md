## Trezor 10 integration gate

The published `@trezor/connect-webextension` 10.0.1 is ESM and uses Suite Desktop or Suite Web external messaging. Migration includes updating the SDK import/types, removing obsolete Connect 9 `connectSrc`/iframe settings, adding the documented `https://suite.trezor.io/*` `externally_connectable` origin, and verifying SDK CommonJS/Jest/webpack interoperability. The existing hardware UTXO test also imports a private Connect 9 module and must migrate to supported interfaces.

Release qualification requires real-device import/address confirmation; EVM legacy/EIP-1559/personal-message/typed-data signing; BTC/SYS UTXO inputs/change checks; rejection, lock, disconnect and reconnect; Suite Desktop and Suite Web fallback; and responses after an idle MV3 worker wakes. Mock-device tests do not establish this physical integration coverage.

## Executed validation

An isolated dependency installation with unchanged `package.json` and the candidate lockfile passed a subsequent frozen-lockfile install (`--ignore-scripts --ignore-optional`). Against the `93501edde` source snapshot, the production Chrome/MV3 webpack build passed with 15 warnings and no errors. Five focused suites passed all 66 tests: installed-SDK hardware EVM and UTXO signing boundaries, ethers browser bundle/signing parity, protected routing, and startup routing. Device I/O in these signing tests is mocked.

An isolated webpack browser fixture verified that PBKDF2 3.1.7 resolves to `browser.js`, `lib/async.js`, and `lib/sync-browser.js`, without the native entry or sync wrapper. Ten vectors passed 40 parity checks against Node crypto across direct browser sync, bundled browser sync, WebCrypto async, and async with WebCrypto explicitly disabled. The vectors cover SHA-512 Unicode/NFKD and a known BIP39 seed, HMAC key-size boundaries, long passwords, and multi-block output; instrumentation confirmed that the fallback made no WebCrypto calls. Other isolated checks passed IP parser/classifier boundary cases, PostCSS rejection of an external synthetic source map, both selector-parser major lines, brace expansion, and YAML merge behavior. A real loopback redirect comparison reproduced the cross-realm custom-header leak in follow-redirects 1.16.1 and verified stripping in 1.16.2, while preserving harmless headers and built-in Authorization stripping. These checks do not claim that every listed upstream advisory was reproduced or that physical hardware was qualified.
