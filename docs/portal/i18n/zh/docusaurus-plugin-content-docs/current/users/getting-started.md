---
title: 用户入门
---

Pali 让你通过一个扩展管理 EVM 账户、Syscoin UTXO 账户和模块化智能账户。

## 基本设置

1. 安装 Pali 扩展。
2. 创建新钱包或导入现有助记词。
3. 设置强密码。
4. 离线备份助记词。
5. 选择要使用的网络。
6. 只连接你信任的 dapp。

## 设置与加载

未完成设置时，请保持设置页面打开并可见。离开、隐藏或重新加载页面会清除设置过程中输入的敏感信息，你可能需要重新开始。请保留已备份的恢复助记词。

如果 Pali 无法确认钱包是否创建完成，请让它重新加载并检查钱包。如果出现解锁页面，请使用刚刚设置的密码。不要因为响应中断就认为钱包尚未创建，也不要立即重复创建。

操作较慢时，Pali 可以显示恢复选项，同时保留导航功能。敏感操作仍会等待账户和网络状态稳定。“收款”会暂时隐藏地址、二维码和复制控件；水龙头领取操作也会等待。继续之前，请再次确认账户和网络。

## 连接 dapp

网站请求访问时，Pali 会打开连接弹窗，显示网站并让你选择账户。dapp 只能获得已连接账户的地址和获准的提供程序状态。

Pali 按网站保存连接。你可以将不同网站连接到不同账户，但每个网站同一时间只能有一个活动账户。

## EVM 账户

EVM 账户适用于兼容 Ethereum 的链、Rollux、Syscoin NEVM，以及需要 MetaMask 风格钱包行为的 dapp。

EVM dapp 可以请求：

- 访问账户
- 发送交易
- 个人消息签名
- 类型化数据签名
- 添加代币监控
- 添加或切换链
- 批量调用

要查找或添加资产，请参阅[代币发现与区块浏览器 API](./token-discovery-and-explorer-apis)。本指南介绍手动导入、支持的 API 格式、网络设置以及服务提供商的访问限制。

## UTXO 账户

UTXO 账户适用于 Syscoin UTXO 和 Bitcoin 风格的交易流程。UTXO dapp 可以请求支持 xpub 的状态信息、找零地址、PSBT 签名和交易广播。

## 智能账户

智能账户是由模块控制的合约账户。Pali 可以创建由通行密钥验证器、钱包控制的 ECDSA 验证器或共同管理策略控制的账户。这些账户适用于 dapp 引导、批量操作和守护者恢复。部分智能账户在首次部署交易之前仅为反事实账户。
