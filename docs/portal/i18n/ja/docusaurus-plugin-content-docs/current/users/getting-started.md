title: ユーザー向けスタートガイド
---

Paliでは、1つの拡張機能からEVMアカウント、Syscoin UTXOアカウント、モジュール式スマートアカウントを管理できます。

## 基本設定

1. Pali拡張機能をインストールします。
2. 新しいウォレットを作成するか、既存のシードフレーズをインポートします。
3. 強力なパスワードを設定します。
4. シードフレーズをオフラインでバックアップします。
5. 使用するネットワークを選択します。
6. 信頼できるdappにだけ接続します。

## セットアップと読み込み

セットアップが完了するまでは、画面を開いたまま表示しておいてください。画面を離れたり、非表示にしたり、再読み込みしたりすると、入力済みの機密情報が消去され、最初からやり直す必要が生じることがあります。バックアップしたリカバリーフレーズは保管しておいてください。

Paliがウォレットの作成完了を確認できない場合は、再読み込みしてウォレットを確認するのを待ってください。ロック解除画面が表示されたら、先ほど設定したパスワードを使います。応答が途切れたからといってウォレットが作成されていないとは限らないため、すぐに作成を繰り返さないでください。

処理が遅い場合、Paliはナビゲーションを使える状態に保ちながら、復旧のための選択肢を表示できます。機密性の高い操作は、アカウントとネットワークの状態が確定するまで待機します。受取画面ではアドレス、QRコード、コピー操作を一時的に非表示にし、フォーセットからの受け取りも待機します。続行前にアカウントとネットワークを再確認してください。

## dappへの接続

サイトがアクセスを要求すると、Paliはサイトを表示する接続ポップアップを開き、アカウントを選択できるようにします。dappが受け取るのは、接続されたアカウントのアドレスと承認済みのプロバイダー状態だけです。

Paliはサイトごとに接続を保存します。異なるサイトを異なるアカウントに接続できますが、各サイトで同時に有効にできるアカウントは1つです。

## EVMアカウント

EVMアカウントは、Ethereum互換チェーン、Rollux、Syscoin NEVM、およびMetaMask形式のウォレット動作を想定するdappで使用します。

EVMのdappは次の操作を要求できます。

- アカウントへのアクセス
- トランザクション
- パーソナル署名
- 型付きデータの署名
- トークンの監視登録
- チェーンの追加・切り替え
- 一括呼び出し

## UTXOアカウント

UTXOアカウントは、Syscoin UTXOおよびBitcoin形式のトランザクション処理で使用します。UTXOのdappは、xpubに対応した状態情報、釣銭アドレス、PSBT署名、トランザクションのブロードキャストを要求できます。

## スマートアカウント

スマートアカウントは、モジュールによって制御されるコントラクトアカウントです。Paliは、パスキーバリデーター、ウォレットが管理するECDSAバリデーター、または共同管理ポリシーで制御されるアカウントを作成できます。dappへの導入、一括操作、ガーディアンによる復旧に役立ちます。初回のデプロイトランザクションまでは、カウンターファクチュアルな状態のアカウントもあります。
